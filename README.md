# 🌧️ CSV Rainfall & Crop Price Analysis

## About This Project
Using Python and Pandas to read, analyze and 
summarize real agricultural data from CSV files. 
This project explores the relationship between 
rainfall patterns and crop market prices for 
Nigerian crops.

## What I Built
- Created and managed agricultural datasets
- Read and wrote CSV files using Pandas
- Generated automatic statistical summaries
- Analyzed crop prices across different seasons

## Tools Used
- Python
- Pandas
- Google Colab

## Crops Analyzed
Maize | Rice | Bean | Tomato | Yam

## Key Skill Learned
Reading and writing CSV files — the standard 
format for sharing research datasets globally
